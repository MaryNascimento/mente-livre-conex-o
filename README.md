# Mente Livre Conexão

Crie um protótipo de aplicativo mobile chamado MenteLivre, uma plataforma que conecta pacientes a psicólogos de todo o Brasil de forma simples, segura e acessível.

O objetivo do aplicativo é facilitar a busca pelo profissional ideal através de filtros personalizados, permitindo que cada usuário encontre um psicólogo compatível com suas necessidades.

Identidade visual

Interface moderna, minimalista e acolhedora.

Cores principais: tons de azul, branco e verde-água (transmitindo calma, confiança e bem-estar).

Design limpo, com cantos arredondados, ícones modernos e boa acessibilidade.

Aparência semelhante a aplicativos como Airbnb e Nubank: simples, organizada e intuitiva.

Observações

O protótipo deve priorizar simplicidade e facilidade de desenvolvimento. Não incluir sistema de pagamento, chat interno, videochamada ou inteligência artificial. O foco é apresentar uma experiência intuitiva de busca e conexão entre pacientes e psicólogos. O aplicativo deve transmitir acolhimento, confiança e profissionalismo.
